# مدار ERP

واجهة عربية RTL لنظام إدارة الأعمال، مبنية باستخدام Next.js وTypeScript.

## التشغيل محلياً

```bash
npm install
npm run dev
```

ثم افتح http://localhost:3000

## الوحدات الحالية
- نظرة عامة ومؤشرات الأداء
- الحسابات والمالية
- المبيعات والفواتير
- المخزون والمنتجات
- الموارد البشرية
- التقارير والتحليلات

> البيانات الحالية توضيحية للعرض التجريبي، ولا يوجد ربط بقاعدة بيانات أو نظام مصادقة بعد.
