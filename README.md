# مدار ERP

واجهة عربية RTL لإدارة المنشآت مبنية باستخدام Next.js وTypeScript.

## التشغيل محلياً
```bash
npm install
npm run dev
```
ثم افتح http://localhost:3000

## الوظائف الحالية
- لوحة مؤشرات تحسب المبيعات والمصروفات وقيمة المخزون من السجلات.
- إدارة الفواتير والعملاء والمنتجات والمخزون والمصروفات والموظفين.
- إضافة وتعديل وحذف وبحث وتصفية السجلات.
- حفظ تلقائي محلي في المتصفح عبر localStorage.
- تصدير الجداول والتقارير بصيغة CSV المتوافقة مع Excel.
- طباعة الفاتورة من المتصفح، ويمكن اختيار Save as PDF من نافذة الطباعة.

## حدود النسخة الحالية
هذه نسخة أولية تفاعلية (MVP). التخزين محلي على نفس المتصفح والجهاز؛ لا يوجد حتى الآن خادم API أو قاعدة بيانات مشتركة أو تسجيل دخول وصلاحيات متعددة المستخدمين أو نسخ احتياطي سحابي. الفاتورة الحالية مبسطة ولا تشمل بعد بنود أصناف متعددة أو ضريبة قيمة مضافة أو ترقيم محاسبي متكامل. لا تستخدمها كسجل مالي رسمي قبل استكمال هذه الأجزاء ومراجعتها محاسبياً.
